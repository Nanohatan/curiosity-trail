# curiosity trail

何にハマって、どんな行動をしたかを記録する個人サイト。
GitHub の草のようなヒートマップで日々の動きを見て、今週・今月・今年の振り返りができる。

## 記録のしかた

スプレッドシートに直接書く（フォームは使わない）。サイトを開いたときにブラウザが直接読み込む（再ビルド不要）。

- シート: `src/lib/sheet.ts` の `SHEET_ID`（「リンクを知っている全員が閲覧可」にしておく）
- **テーマIDごとのシート**（T01, T02, …）に、そのハマりごとの記録を書く
  - 列: 日付 / 期間（終了日。空ならその日だけ）/ 何をした / 熱量 / 表示タイトル名
  - 期間を書くと、日付から終了日まで毎日その作業をしていた扱いになる。草・今週や今月の集計には毎日出し、「最近の記録」や件数では 1 件（「11月17日 / 〜22日」）にまとめる
  - 表示タイトル名は名前を決めた・変えた行にだけ書く（最初は E2）。サイトは日付がいちばん新しい表示タイトル名を名前に使い、変わった日の記録に「名前を変更：前 → 後」、個別ページに名前の変更履歴を出す。テーマIDでまとめるので、名前を変えても同じハマりごとのまま
- **テーマ** シート（1テーマ1行の台帳）: テーマID / 表示名（各シートの E2 から自動）/ カテゴリ / 派生元ID / きっかけ / 開始日 / 終了日 / 終了理由
  - 新しいハマりごと: 次のIDでシートを足し（T08 など。上の列をそのまま使う）、テーマに 1 行足して表示名の数式を下にコピーする。何かから派生したら派生元IDに元のテーマIDを書く
  - 飽きた: テーマの終了日と終了理由（任意）を書く。終了日が最後の記録と同じかそれより後ならクローズ。あとで記録を書けば「ハマり中」に戻る
- **ログ_自動**: テーマに載っている ID のシートを全部まとめる数式。直接は書かない
- サイトが読むのは数式で作られる **公開用_ログ**（`LOG_GID`）と **公開用_クローズ**（`CLOSE_GID`）。この 2 つにも直接書かない
- 状態は自動: 最後の記録から 1 か月たつと「休眠中」、それまでは「ハマり中」
- 以前のフォームの回答などは `archive_` 付きのタブに残してある（サイトは読まない）
- 個別ページは `/interest/?id=テーマID`（前の形の `?name=名前` も、今の名前・前の名前で開ける）
- カテゴリページ（`/categories/`）は、カテゴリとハマりごとをワードクラウドで表示。文字の大きさは記録の件数
- 読書予定メモ（`/books/`）は同じシートの「読みたい本メモ」タブ（`src/lib/books.ts` の `BOOKS_GID`）から。列は ISBN / タイトル / 作者 / 出版社 / 出版年月 / 読み終わり（日付・チェック・「済」など。何か入っていれば読了扱いで、日付なら読了日も出す）。タイトルは国立国会図書館サーチへのリンク
- やりたいこと（`/wishes/`）は同じシートの「やりたいこと」タブ（`src/lib/wishes.ts` の `WISHES_GID`）から。列は タイトル / メモ（見出しが空ならタイトルの右隣の列をメモとして読む）

## 草の色

- **アクション数**: その日に記録した行動の数（1 / 2–3 / 4–5 / 6 以上）
- **カテゴリ数**: その日に触れたカテゴリの数（1 / 2 / 3 / 4 以上）

右上で「直近1年」と年ごとの表示を切り替えられる。マスを押すとその日の記録が出る。
「今週・今月・今年」の集計は見ている人のブラウザで計算するので、再ビルドしなくても日付に合わせて更新される（週は月曜始まり）。

## コマンド

| コマンド | 内容 |
| :-- | :-- |
| `npm install` | 依存関係のインストール |
| `npm run dev` | `localhost:4321` で確認 |
| `npm run build` | `./dist/` にビルド |
| `npm test` | 日付・集計ロジックのテスト |

## GitHub Pages で公開する

1. GitHub にリポジトリを作って push する
2. リポジトリの Settings → Pages → Build and deployment の Source を **GitHub Actions** にする
3. `main` に push するたびに `.github/workflows/deploy.yml` がビルドして公開する

URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）は Actions が自動で設定するので、`astro.config.mjs` を書き換える必要はない。

## 構成

```text
src/
├── lib/sheet.ts             スプレッドシートの読み込み（テストあり）
├── lib/trail.ts             日付・集計の計算（テストあり）
├── lib/cloud.ts             ワードクラウドの配置（テストあり）
├── lib/books.ts             読みたい本タブの読み込み（テストあり）
├── lib/wishes.ts            やりたいことタブの読み込み（テストあり）
├── scripts/app.ts           読み込みとページの描画
├── scripts/trail-client.ts  草と振り返りの描画
├── components/Trail.astro   草のコンポーネント
└── pages/                   トップ / 一覧 / 個別ページ
```
